# mini-rag 
this is a minimal implementation of rag model for questions answering

## Requirements 
- python 3.8 or later 

#### install python using miniconda 
1) download and install miniconda from [here]()
2) create virtual environment using this command 
```bash
$ conda create -n mini-rag-app python=3.8
```
3) activate the VENV
```bash 
$ conda activate mini-rag-app
```
